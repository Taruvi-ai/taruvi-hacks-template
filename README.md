# Reusable Codex App-Development Template

This repository contains only reusable Codex framework assets for Taruvi/Refine app development workflows, MCP integration, and Langfuse observability hooks.

## Included
- `AGENTS.md`
- `.agents/` skill packs
- `.agent/` local shell hooks and subagents
- `.codex/` hook scripts, config template, codex skills/subagents
- `skills/` and `subagents/` reusable templates
- MCP config templates (`.mcp.example.json`, `.vscode/mcp.json`)
- Langfuse observability integration scripts and tests
- setup and audit documentation

## Excluded
- app source code
- runtime/build artifacts
- local logs/session files
- auth files and secrets

See `INSTALL.md`, `QUICKSTART.md`, `LANGFUSE_SETUP.md`, and `TEMPLATE_AUDIT.md`.
